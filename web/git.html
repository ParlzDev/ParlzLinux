parlz.git 就地改造的 linux-7.2.5/ 内核树、userland/（56 个 .c：sh / login / install / cpfs / mkfs / ifc / pm 等）、scripts/（86 个 .sh + 30 个 .py 构建与验收）、web/ 本站与模拟机，以及 NTCLKS-main/ 那条 Ring-0 支路 main rc.0.1

只读镜像：谁都能 clone/fetch，推送只走服务器本机或 SSH。两个地址指向同一份裸库 —— git.os.parlz.com 子域与服务端 /git/ 那条 location 真正上线之前，clone 是连不上的；这里列的是待上线的地址，不是坏链接找借口。

读不到导出数据（git/manifest.js）。

跑一次 sh scripts/web-git-export.sh 生成；没有它，这一页照样列出下面的克隆地址与说明。

克隆

https://www.parlz.com/git/parlz.git

https://git.os.parlz.com/parlz.git 

$ git clone https://www.parlz.com/git/parlz.git
$ cd parlz && git log --oneline -5
$ git tag -l                          # 发布号与 /etc/parlz-release 同源
$ sh scripts/build-2404.sh            # 全链构建（WSL Ubuntu-24.04）

发布 / 更新

# 构建机 → 服务器（SSH，仅此一条写入路径）
$ git push --mirror ssh://jgzyes@git.os.parlz.com/srv/git/parlz.git
$ git update-server-info              # 服务器上刷新仓库信息

产物（ISO / IMG / .pm）不进仓库：它们走本站的下载与 feed，仓库里只放源码与脚本。
