parlz

在 Linux 7.2.5 源码上就地改造的操作系统： 内核自带 Parlz 标识层，用户空间是静态 BusyBox 加自研的 sh / login / install / pm。 装上硬盘能自举，也能把裁掉的命令从包装回来。

hello.py · Python · python3 hello.py
#!/usr/bin/env python3
# hello.py - the first program on ParlzOS

def main():
    print("Hello, World from ParlzOS!")

if __name__ == "__main__":
    main()
