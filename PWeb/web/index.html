PWeb lightweight

PWeb is a tiny C web server - a single ~8k-loc codebase with a nginx-like config. It ships static files, 301 rewrites, reverse proxies, CGI, gzip, basic auth, and virtual hosts, while running comfortably on a 0.5 core / 512 MB box.

PWeb keeps its RSS flat: no full-file buffering, streaming proxies, and no per-connection memory growth. The event model is one worker thread per connection, so it scales by just adding threads instead of buffering.
